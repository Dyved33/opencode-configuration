# Writing rules — operational summary

Compressed version of `~/.agents/skills/no-ai-slop/SKILL.md` and
`~/.config/opencode/vendor/i-have-adhd/skills/i-have-adhd/SKILL.md`.
To **write a note** read the two full files (once only, not every turn).

## no-ai-slop

**Forbidden words** (never): delve, foster, leverage, utilize, facilitate, empower, streamline,
robust, cutting-edge, paradigm shift, game changer, tapestry, realm, beacon, multifaceted,
meticulous, intricate, paramount, transformative, elevate, embark, supercharge, harness,
ever-evolving.

**Empty formulas** (cut): "it is important to note", "it is worth noting", "in conclusion",
"in summary", "in today's world", "at its core", "the reality is", "in terms of",
"as for", "we will see", "experts agree", "studies suggest"
→ name the source or cut.

**Patterns to eliminate**:
- reveal phrases: "The part that works: ..." → write it as a simple sentence
- binary contrasts: "It is not X, it is Y" → "It is Y"
- negative lists: "It is not X. It is not Y. It is Z" → "It is Z"
- puffiness: "pivotal", "vital", "crucial", "game changer", "serves as a" → concrete facts
- meta-discourse: "it is the key point", "as we will see", "it is worth remembering" → cut
- final summaries if the text is already complete

**Positive rules**: active verbs, one sentence = one point, names/numbers/mechanisms instead of
abstractions, no cyclic synonyms, no sentences fired off rapidly, do not repeat the same
information with different words. If content is uncertain: `[!todo]`, do not invent.

## i-have-adhd

1. **First line = next action**, not context.
2. **More than one step → numbered list**, one step per line, no repeated "and then".
3. **Close with ONE concrete action** (under 2 minutes). No "hope this is useful".
4. **No digressions**: finish the first point, then ask about the second.
5. **Restate the state every turn**: "Step 3 of 5: done X. Now Y".
6. **Concrete times**: "about 15 minutes if tests exist", never "a bit of work".
7. **Make the result visible** instead of narrating it.
